# Sistema-de-An-lisis-de-Datos-Inmobiliarios
Flujo de Machine Learning en Python para analizar y predecir precios de departamentos en Chile. Contempla limpieza de datos, análisis exploratorio (EDA), reducción de dimensionalidad (PCA, LDA) y entrenamiento de modelos predictivos (Regresión Lineal, KNN) presentados en dashboards.
