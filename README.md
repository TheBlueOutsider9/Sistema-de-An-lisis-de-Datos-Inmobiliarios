Sistema de Análisis de Datos Inmobiliarios 

📖 Descripción del Proyecto
En el competitivo mercado inmobiliario chileno, comprender los factores que determinan el valor de las propiedades es fundamental para la toma de decisiones estratégicas. Este proyecto consiste en el desarrollo de un sistema analítico automatizado que permite modelar y predecir el precio de venta de departamentos en Chile en función de sus atributos estructurales.La herramienta busca reducir la incertidumbre y asimetría de información en el mercado, beneficiando tanto a empresas administradoras de bienes raíces como a compradores particulares.

✨ Características Principales: El flujo de trabajo del sistema abarca todo el ciclo de vida de los datos:Limpieza y Preprocesamiento: Carga del dataset viviendas_chile.csv, tratamiento de variables categóricas (conversión a binarias) y eliminación de valores atípicos (outliers).Análisis Exploratorio de Datos (EDA): Análisis univariado y multivariado para comprender distribuciones y relaciones entre variables (precio, metros útiles, habitaciones, baños, etc.) mediante histogramas, boxplots y matrices de correlación.Ingeniería de Características: Creación de la métrica clave Precio_m2 (precio por metro cuadrado) para reducir la variabilidad atribuible únicamente al tamaño de la propiedad.Modelado Predictivo: Implementación y entrenamiento de modelos de Machine Learning: Regresión Lineal y K-Nearest Neighbors (KNN).Reducción de Dimensionalidad: Aplicación de Análisis de Componentes Principales (PCA) y Análisis Discriminante Lineal (LDA) para optimizar el rendimiento y eficiencia de los modelos.Visualización de Resultados: Generación de dashboards integrados para facilitar la interpretación visual y la presentación ejecutiva de los hallazgos.

🛠️ Tecnologías Utilizadas: El proyecto fue desarrollado íntegramente en la nube utilizando las siguientes herramientas:Lenguaje: Python.Entorno: Google Colab.Manipulación de Datos: Pandas, NumPy.Visualización: Matplotlib, Seaborn.Machine Learning: Scikit-Learn (LinearRegression, KNeighborsRegressor, StandardScaler, PCA, LDA).

📈 Resultados Clave: Tras la evaluación de los modelos mediante métricas de rendimiento (MAE, RMSE y $R^2$), se obtuvieron las siguientes conclusiones:El modelo que entregó los mejores resultados predictivos fue KNN combinado con reducción por LDA, logrando un coeficiente de determinación ($R^2$) de 0.691.Esta combinación superó tanto a la Regresión Lineal como al algoritmo KNN sin reducción de dimensionalidad, presentando el menor error absoluto medio (aprox 59.07$ millones) y el menor error cuadrático medio (RMSE $\approx 78.42$ millones).Se demostró que variables individuales como la cantidad de habitaciones o baños tienen bajo poder explicativo por sí solas, mientras que el análisis del Precio_m2 estructuró de manera más definida la valoración del mercado.
